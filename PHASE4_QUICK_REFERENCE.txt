================================================================================
TROUBLESHOOTING
================================================================================

If you get "ORA-01438: value larger than specified precision":
- Ensure table columns have appropriate NUMBER sizes
- Check INSERT statements for values exceeding column precision

If you get "ORA-00955: name is already used by an existing object":
- Drop existing objects before re-running: DROP PROCEDURE procAddEvent;
- Or use CREATE OR REPLACE for procedures/functions/packages

If DBMS_OUTPUT shows no output:
- Execute: SET SERVEROUTPUT ON SIZE 20000;
- Or increase size: SET SERVEROUTPUT ON SIZE 50000;

If function returns NULL:
- Check NVL() usage in function to handle NO_DATA_FOUND
- Verify WHERE clause in function matches expected data
