│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ trgBeforeEventInsert (ON Event.INSERT)                              │  │
│  ├──────────────────────────────────────────────────────────────────────┤  │
│  │ • Timing: BEFORE INSERT                                             │  │
│  │ • Actions:                                                           │  │
│  │   ├─ Auto-generates event_id if NULL                                │  │

│  │ • Business Value: Automatic ID generation                           │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ trgAfterPaymentUpdate (ON Payment.UPDATE)                           │  │
│  ├──────────────────────────────────────────────────────────────────────┤  │
│  │ • Timing: AFTER UPDATE                                              │  │
│  │ • Actions: Inserts into AuditLog                                    │  │
│  │   ├─ Captures: OLD values, NEW values                               │  │
│  │   ├─ Records: USER, SYSDATE                                         │  │
│  │   └─ Stores: Operation, old_value, new_value                        │  │
│  │ • Purpose: Complete audit trail for compliance                      │  │
│  │ • Business Value: Payment change tracking                           │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │

│  │ • Timing: AFTER DELETE                                              │  │
│  │ • Actions: Archives to DeletedTickets                               │  │
│  │   ├─ Preserves: All ticket data                                     │  │
│  │   └─ Adds: deleted_date = SYSDATE                                   │  │
│  │ • Purpose: Data preservation instead of loss                        │  │
│  │ • Business Value: Historical tracking, audit trail                  │  │

CURSOR ARCHITECTURE:

EXPLICIT CURSOR (procProcessEventParticipants):
┌──────────────────────────────────────────────┐
│ CURSOR c_participants IS                     │
│   SELECT p.participant_id, p.full_name, ... │
│   FROM Participant p                         │
│   JOIN Ticket t ON ...                       │
│   WHERE t.event_id = p_event_id              │
└──────────────┬───────────────────────────────┘
               │
        ┌──────▼──────┐
        │ OPEN cursor │
        └──────┬──────┘
               │
        ┌──────▼──────────────────┐
        │ LOOP                     │
        │   FETCH INTO variables   │
        │   EXIT WHEN %NOTFOUND    │
        │   DBMS_OUTPUT            │
        │ END LOOP                 │
        └──────┬──────────────────┘
               │
        ┌──────▼───────┐
        │ CLOSE cursor │
        └──────────────┘

PARAMETERIZED CURSOR (procGenerateVenueOccupancyReport):
┌──────────────────────────────────────────────┐
│ CURSOR c_venue_occupancy                     │
│   (p_start DATE, p_end DATE) IS              │
│   SELECT v.venue_name,                       │
│          COUNT(DISTINCT e.event_id) as count │
│   FROM Venue v                               │
│   WHERE e.event_date BETWEEN p_start p_end   │
└──────────────┬───────────────────────────────┘
               │
        ┌──────▼──────────────────────┐
        │ FOR rec IN c_venue_occupancy │
        │   (p_start_date,             │
        │    p_end_date)               │
        │   DBMS_OUTPUT rec.venue_name │
        │ END LOOP                     │
        └──────────────────────────────┘

EXCEPTION HANDLING HIERARCHY:
═══════════════════════════════════════════════════════════════════════════════

procAddEvent:
  ├─ DUP_VAL_ON_INDEX → "Event ID already exists"
  └─ OTHERS → Generic error with SQLERRM

procRegisterParticipant:
  ├─ v_invalid_gender → "Invalid gender. Must be M or F" + ROLLBACK
  ├─ v_duplicate_email → "Email already registered" + ROLLBACK
  └─ OTHERS → Generic error + ROLLBACK

procProcessPayment:
  ├─ NO_DATA_FOUND → "Ticket not found" + ROLLBACK
  ├─ v_error → "Invalid payment method" + ROLLBACK
  └─ OTHERS → Generic error with SQLERRM + ROLLBACK

Functions:
  ├─ NO_DATA_FOUND → Return default/0
  └─ OTHERS → Return error message

Anonymous Blocks:
  └─ WHEN OTHERS → DBMS_OUTPUT error message
