BUSINESS LOGIC EXPLANATION
================================================================================

1. EVENT CREATION FLOW
   • procAddEvent is called with event details
   • Auto-generates unique event_id
   • BEFORE INSERT trigger validates and sets defaults
   • Event created with COMMIT
   • Returns generated ID to caller

2. PARTICIPANT REGISTRATION
   • procRegisterParticipant validates gender and email
   • Raises named exceptions for invalid data
   • ROLLBACK on error to prevent corruption
   • Auto-generates participant_id
   • Clear error messages for user feedback

3. PAYMENT PROCESSING
   • procProcessPayment validates payment method
   • Creates payment record with auto-generated payment_id
   • Calls nested procUpdateTicketBooking for consistency
   • AFTER UPDATE trigger logs change to AuditLog
   • Returns status for error handling

4. TICKET ARCHIVAL
   • When ticket is deleted from system
   • AFTER DELETE trigger captures record
   • Archives to DeletedTickets with deletion timestamp
   • Preserves historical data for analysis

5. PACKAGE OPERATIONS
   • procGetEventSummary displays event statistics
   • Increments package variable g_total_events_processed
   • fnCalculateEventProfit calculates revenue minus budget
   • Package encapsulates related event operations
