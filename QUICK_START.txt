================================================================================
EVENT MANAGEMENT SYSTEM - QUICK START GUIDE (5 MINUTES)
================================================================================

PREREQUISITES CHECKLIST:
✓ Node.js installed (node --version)
✓ Oracle Database running (or Instant Client installed)
✓ Oracle database credentials ready

================================================================================
STEP 1: INSTALL DEPENDENCIES (30 seconds)
================================================================================

Navigate to project folder and run:
    npm install

This installs: express, cors, oracledb, dotenv

================================================================================
STEP 2: CREATE .env FILE (1 minute)
================================================================================

Create a file named ".env" in the project root with:

    DB_USER=system
    DB_PASSWORD=your_oracle_password
    DB_CONNECTION_STRING=localhost:1521/XE
    PORT=3000

Replace "your_oracle_password" with your actual Oracle password.

For different Oracle versions:
- Oracle 21c XE: localhost:1521/XE
- Oracle 11g: localhost:1521/orcl
- Custom: host:port/service_name

================================================================================
STEP 3: LOAD DATABASE SCHEMA (2 minutes)
================================================================================

Open Oracle SQL*Plus or SQL Developer and execute:

    @01_CREATE_TABLES.sql
    @02_INSERT_DATA.sql
    @03_CONSTRAINTS.sql
    @04_VIEWS.sql
    @05_INDEXES.sql
    @06_PLSQL.sql

Execute them IN THIS ORDER. This creates all tables, data, views, indexes,
and Phase 4 PL/SQL components (procedures, functions, triggers, cursors, package).

================================================================================
STEP 4: START THE SERVER (10 seconds)
================================================================================

Run:
    node server.js

You should see:
    Server listening at http://localhost:3000

If you see an error, check:
- Is Oracle database running?
- Is .env file created with correct credentials?
- Is Oracle Instant Client installed?

================================================================================
STEP 5: ACCESS THE APPLICATION
================================================================================

OPEN IN BROWSER:

Public Website:
    http://localhost:3000

Admin Dashboard (Password: "admin"):
    http://localhost:3000/admin.html

================================================================================
COMMON ERRORS & FIXES:
================================================================================

ERROR: "Cannot find module 'oracledb'"
FIX: npm install oracledb

ERROR: "ORA-12514: TNS:listener does not currently know of service"
FIX: Check DB_CONNECTION_STRING in .env (should be localhost:1521/XE)

ERROR: "ORA-01017: invalid username/password"
FIX: Check DB_USER and DB_PASSWORD in .env

ERROR: "Port 3000 already in use"
FIX: Change PORT in .env to 3001 or close other app using 3000

ERROR: "Cannot find module 'express'"
FIX: Run "npm install" first
