================================================================================
DATA FLOW EXAMPLES
================================================================================

Example 1: Register Participant
───────────────────────────────
User Input (form) 
  ↓
JavaScript (admin.js) 
  ↓
fetch() POST /plsql/registerParticipant 
  ↓
Node.js (server.js) 
  ↓
PL/SQL Procedure: procRegisterParticipant 
  ↓
Database INSERT + VALIDATION 
  ↓
Success/Error response 
  ↓
Display message to user

Example 2: Event Analytics
──────────────────────────
User selects event 
  ↓
JavaScript (admin.js) calls loadEventAnalytics() 
  ↓
fetch() GET /admin/plsql/eventSummary/:eventId 
  ↓
Node.js queries:
  - Event details
  - fnCalculateTotalEventRevenue(:eventId)
  ↓
PL/SQL Function calculates: SUM(price) from tickets 
  ↓
Calculate Profit = Revenue - Budget 
  ↓
Return JSON with all metrics 
  ↓
Display in UI with formatted numbers

Example 3: Venue Occupancy
──────────────────────────
User selects venue 
  ↓
JavaScript (admin.js) calls loadVenueOccupancy() 
  ↓
fetch() GET /admin/plsql/venueOccupancy/:venueId 
  ↓
Node.js executes:
  - Get venue details
  - Get events at venue (using cursor)
  - Count attendees per event
  ↓
PL/SQL Cursor iterates event list 
  ↓
For each event: COUNT(*) from tickets 
  ↓
Calculate: (attendees / capacity) * 100 = occupancy % 
  ↓
Return JSON with venue + events array 
  ↓
Display in table format with occupancy percentages
